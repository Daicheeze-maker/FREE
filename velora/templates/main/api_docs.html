How to use it

  1. Get a token: POST /api/v1/auth/token with {"email": "...", "password": "..."}.
  2. Send it on every request that needs an account: Authorization: Bearer <token>. Tokens last {{ config.API_TOKEN_HOURS }} hours.
  3. Send request bodies as JSON (Content-Type: application/json).

Status codes: 200 OK · 201 Created · 204 No Content · 400 bad request · 401 not signed in · 403 not allowed · 404 not found · 405 wrong method · 409 conflict (sold out, not enough credit, wrong order step) · 415 not JSON · 422 a field needs fixing · 429 too many attempts · 502/504 an outside service failed or timed out · 503 unavailable.

Errors always look like {"error": {"status": 422, "code": "validation_failed", "message": "...", "fields": {"price": "Required."}}}.

Full guide with examples: docs/API.md in the project folder. Machine-readable list: GET /api/v1.

Outside APIs the store uses

  • Frankfurter (European Central Bank rates): display currencies. Through this API: GET /api/v1/rates.
  • Mapbox or OpenStreetMap Nominatim: turns a map pin into an address. Through this API: GET /api/v1/geocode/reverse.
  • Also: OpenStreetMap map tiles, Pexels and Openverse photos, Open Food Facts import. All have timeouts and fall back gracefully.
